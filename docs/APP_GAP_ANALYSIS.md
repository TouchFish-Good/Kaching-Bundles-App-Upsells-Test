## 功能与测试债务

- 活动 CRUD、范围重叠、价格计算、市场金额、组合规则、Variant 库存、原子加购、翻译回退没有真实 API/数据库/Function 集成测试。
- 分析需要定义“新增收入/每访客收入/转化”的归因口径。无数据来源前不能填模拟收入并声称实用。
- 真实 SHOPLINE 店铺尚未接入。白名单和 Function 跨 Variant 能力是用户提供的前提，仍需在目标店铺的 API/结账测试确认。
- 原参考的数据修改、发布、删除、计费、安装路径未操作；涉及它们的行为仅能通过安全只读证据和本地需求设计，不标 `VERIFIED`。
