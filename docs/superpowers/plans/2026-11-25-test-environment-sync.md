# 测试环境功能同步计划

**目标：** 将源目录当前功能同步到用户指定的测试目录，保留测试应用与扩展身份。

**依据：** 用户本轮同步指令、源目录 AGENTS.md 与 docs/REQUIREMENTS.md、DESIGN_SPEC.md、USER_FLOWS.md、COMPONENTS.md。

**执行方式：** 当前会话直接执行；用户已指定独立测试目录，无需再建 worktree。仅本地修改，Git 提交和推送等待本批授权。

## 约束

- 不改源目录；不复制源 .git、依赖缓存、构建产物、数据库、密钥或扩展身份文件。
- 测试目录现有 .env.prod、主题元数据、App Key、App Secret、扩展 UUID、应用 URL、回调与数据库保持测试身份。
- 源代码内置正式 Function ID 和主题 API 域名必须改用测试环境；不复制正式 Worker 域名、D1 ID 或管理服务绑定。
- 测试扩展当前 UUID 为 dev 标识，只保留当前身份，不声称它已经发布或经平台验证。
- 同步现有 UI，不重新设计或手改焦点样式；不将自动化/构建成功等同于实店验收。

## 重点复核

1. 主题请求和 Webhook 不能落到正式域名。
2. 缺省 Function ID 必须指向当前测试扩展 UUID，环境变量仍可覆盖。
3. 两份扩展 .env.prod 与现有 SQLite 必须字节不变。
4. .dev.vars/本地 .env 不得进入 Git 候选文件。
5. 未创建测试 Cloudflare 资源、未发布扩展的能力明确标记未验证。
