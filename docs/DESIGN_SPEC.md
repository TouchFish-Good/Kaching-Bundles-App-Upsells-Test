## 活动级 Style 创建页（2026-10-15）

- 标签位置为活动级设置，默认右上角，四种布局一致；也可选“副标题下方”，此时标签作为档位文案流的一部分出现。Horizontal/Grid 的右上角标签不能因列布局而落入普通内容行。
- 颜色增加规格标题、规格值、规格价格、商品序号、规格值普通/选中边框、加购按钮背景/文字、预计节省金额和购物车规格明细；字号/字重增加规格标题、规格值（含下拉框）、规格价格、商品序号、预计节省金额与购物车规格明细。旧活动缺少的外观字段按默认值补齐，原有自定义色值保留。

## 设计意图

产品采用“精密零售运营台”方向：信息密度适中、结构有秩序、价格与状态的变化一眼可扫读。后台不做营销式大卡片；用稳定的侧栏、内容带、表格和紧凑表单支持高频运营。店铺组件则更轻、更直接，把数量、价格和节省额作为主信息。

该方案学习了成熟 Quantity Breaks 的任务结构（活动管理、档位配置、商品页选择、实时预览），未使用其品牌、素材、文案或代码。

## 页面规格

### Dashboard

- 首屏为活动健康概览：Active、预计促销销售额、组件覆盖率、到期提醒。
- 下方为最近活动和“需要注意”列表；空状态给出创建入口。
- KPI 是导航上下文，不绘制无意义图表。

### Campaign list

- 顶部标题、活动计数和“Create campaign”。
- 搜索、状态下拉、时间筛选位于同一工具栏。
- 表格行含状态徽章、档位摘要、排期与行内更多菜单；小屏切换为可扫描的活动列表。

### Create/Edit campaign

左右双栏：主栏按“基础信息 → 商品范围 → 数量档位 → 排期”编排，右栏是实时规则摘要。保存区固定在页面底部，始终可见。

阶梯以带单选推荐标记的紧凑表格编辑，新增档位不改变已有表单位置。无效字段用字段下方文字说明，避免只在 toast 中报错。

“商品范围”在保存、启用和 Scheduled 进入生效前均运行重叠检查。只有两个指定商品活动的交集会显示活动名、状态、相交商品数和前往处理的入口，发布按钮保持禁用；暂停/结束/删除原活动后才解除。指定商品与指定商品分类的交集不阻止发布：分类选择器在展开成员后显示每个受影响商品及其已生效的指定商品活动，并说明“指定商品规则优先”。Function 对同一商品仅应用指定商品规则。两个指定商品分类活动的交集不阻止发布，Function 将分类候选交由 SHOPLINE 的原生优先级（最近更新的规则优先）处理。范围为分类时，以当前成员展开的结果判断，并在生效前复查。

“币种与叠加”独立成组：默认选中 Shop currency，商品折扣叠加开关固定为关闭。Order 和 shipping 只在 Shop currency 模式下显示，商家可分别选择。选择 Market-specific fixed amount 后，界面显示当前市场显示价的说明，全部叠加开关锁定关闭，并明确说明命中行不会进入其他折扣门槛或分摊。该分组不把 Product Discount Function 误呈现为订单或运费折扣能力。

### Widget studio / preview

左侧配置采用分组折叠区，右侧为带设备切换的真实比例预览。预览外框不是卡片嵌套：它模拟商品页的留白与真实商品信息，并让组件成为核心。

增加 Locale 控制区。商家选择默认文案语言并维护 11 个支持语言的翻译，分别为 `en`、`fr`、`de`、`es`、`it`、`nl`、`sv`、`tr`、`pt-BR`、`zh-Hans`、`zh-Hant`。每个语言行显示 Complete / Missing 状态；Missing 不是错误，预览应显示实际会采用的回退文案及其来源语言。预览设备旁增加 locale 下拉框，便于在桌面与移动端检查文本长度、方向和换行。

### Variant bundle composer

选中多件档位后，当前 Quantity Breaks 档位卡片自身展开为“Choose your items”区域，其他档位保持紧凑。每个槽位有稳定序号、所选 Variant 单价和库存状态；桌面端以紧凑的两列 option 控件排布，移动端按槽位单列展开，减少横向滚动。

选择器从 `product.options` 渲染。Swatches 只在 option 值被产品数据声明为色彩值时使用；其余 option 自动回退为可访问的 Button group 或 Dropdown，避免把“容量”等非色彩属性伪装成色板。规格值使用可换行 Flex 布局，在一行内尽量显示多个值并统一左对齐。商家也可选择 Variant Image tiles：每项使用商品目录中对应 Variant 的原款式图，且可配置图片尺寸、圆角及是否显示 Color 色值。组合可用性在每次 option 选择后重新计算：无此组合为禁用，存在但不可售显示 Sold out，库存不足显示剩余数量。纯文本选择器仅在缺货值上显示 Sold out；售罄图片款式保持可见但不可选择，并以禁用状态、降低透明度和可访问名称表达。Widget 正文字号可配置，预览须在桌面和移动端保持无重叠。

金额摘要始终展示原价、预估折扣、预计总价；默认将相同 SKU 汇总显示为 `Black / M × 2`，但保留槽位级别选择的可追溯性。按钮在验证中显示 loading，在失败时呈现明确可恢复的失败行。

## 交互与反馈

- 按钮按下 120ms 缩放/明暗反馈；面板切换 180ms 透明度过渡；支持 `prefers-reduced-motion`。
- 保存显示“Saving...”并在完成后显示成功 toast；原型延迟 700ms 模拟。
- 删除使用模态确认，明确活动名和不可逆结果。
- Toggle 立即更新行状态，toast 提供 “Undo”。
- 加入购物车为演示反馈，只显示数量与价格，不请求网络。
- 市场币种模式在原型中显示为受控预览：如店铺没有被开通市场币种 Function 能力，保存时应显示“该店铺尚未开通”，而不是静默降级为店铺币种。
- 槽位增加或恢复使用 180ms 高度/透明度过渡；不做连续自动动画。减少动态效果偏好下直接显示最终状态。

## 基础无障碍

活动外观的字体设置按商品页组件显示顺序排列：组件标题、档位、标签、每件规格、购物车明细、价格汇总、结账提示、加购按钮。编辑器不再展示通用“正文字号”；汇总标签、汇总金额与结账提示各有独立字号和字重。规格价格样式同时作用于每件规格的单价及购物车明细右侧金额，左侧规格文字仍由“购物车规格明细”控制。加购按钮默认上下内边距为 14px，仅影响商品页组件。旧活动的 `bodyPx` 保留为只读兼容字段，不再驱动活动预览。 所有字号输入以正整数 px 保存，不设字号上限，移除原 5px 最小值及 20px / 28px 上限；PC 与移动端规则一致。字重、图片尺寸、间距和圆角继续使用各自的校验规则。

价格汇总的 `Original`、`Bundle total` 标签和右侧金额分别使用活动级“汇总文字颜色”与“汇总金额颜色”；预计节省金额保留独立颜色。“预计节省标题”紧邻“预计节省金额”提供独立字号和字重控件，支持全部 16 种应用语言；PC / 移动端分别保存。标题默认 11px / 400，金额默认 11px / 700；两者不得被汇总金额的移动样式覆盖。主题区域标题未配置时使用当前主题语言默认文案，主动清空则隐藏。价格汇总行使用相对行高与可换行布局，字体调大时由内容撑开高度，不依赖固定 17px 行高。旧活动未包含新增颜色时分别回退到 `#666666`、`#171717`。

- 所有图标按钮有 `aria-label` 和原生 `title`。
- 键盘焦点使用 2px Sea 外环，最小触达区域 40px。
- 数量档位使用 `role=radiogroup` 与原生 radio；状态同时以文字和颜色表达。
- 成功、错误、加购消息写入 `aria-live=polite`。
- 无效 Variant、售罄和库存不足使用 `disabled`、可见文本和关联的错误说明；每个槽位用 `fieldset/legend` 建立名称与选项的关联。
- 翻译编辑器中的 Missing 状态不能只依赖颜色；必须附带语言名、状态文字和可访问名称。语言切换后保留当前未保存内容并提示保存状态，不应覆盖其他 locale 的草稿。
