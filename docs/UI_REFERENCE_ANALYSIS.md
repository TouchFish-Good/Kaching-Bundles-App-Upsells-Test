# Kaching Bundles UI 参考实测

## 范围与证据

- 观察日期：2026-10-14。参考为用户在 Codex 内置浏览器打开的 Shopify Admin 中 Kaching Bundles 首页、现有活动编辑页，以及 `The Collection Snowboard: Liquid` 商品预览页。
- 证据类型：浏览器视口截图、可访问性/DOM 快照、少量 `getComputedStyle` 与元素矩形读取。截图在本次对话的浏览器工具输出中，未保存到仓库；本文不包含带认证参数或 `preview_key` 的完整 URL。
- 观察到的常规视口约为 1037 x 929；另对前台做过 390 x 844 移动视口观察，随后已重置浏览器视口覆盖。
- 这是视觉与交互参考，不复制 Kaching 的代码、品牌图标、促销素材或与一期无关的业务模块。Shopify Admin 的系统外壳与嵌入应用内容需要分开看待；SHOPLINE 不应假装拥有 Shopify 系统导航。

## 后台活动编辑页

- 顶部 Shopify 操作栏为“保存为草稿 / 发布 / 更多操作”。应用内容在一个白色主容器内，按折叠区域顺序排列：产品、设置、样式、各优惠栏、其他可选模块；底部是预览。当前观察到产品区、设置区、样式区和两个优惠栏。
- 产品区使用“所有产品 / 已选产品 / 已选产品系列”单选组，并提供“选择例外”。
- 设置区含内部名称、区块标题、购物车/结账折扣名称；市场可见性、生效日期；每件不同多属性、单数量档位显示多属性、隐藏不可用选项、默认多属性等；定价、购物车和低库存提醒。此处证明参考 UI 将 Variant 行为放在活动级设置中。
- 样式区有布局选项“垂直 / 水平 / 网格 / 简约”、8px 圆角半径值及间距滑块；颜色按常规、优惠栏文本、标签、胶囊色板等分组；字体排版分别可配区块标题、标题、副标题、标签等。当前字段显示 14px 区块标题、20px 标题、14px 副标题、12px 标签。
- 每个优惠栏自身含数量、价格方式（原价、百分比折扣、减免金额、固定价格）、标题、副标题、标签、默认选中与多属性相关选项。观察到 Single 数量 1/原价，Duo 数量 2/单件 15% 折扣；Duo 的副标题与标签使用变量占位表达动态节省额。档位标题和促销标签不是独立于档位的全局设置。
- 预览区有产品和国家/地区选择框，显示两档组件；编辑页面顶部和底部均有保存/发布操作。当前截图中还出现折扣额度、活动大小、应用嵌入提示，这些是真实参考页状态，不代表原型必须模拟相同店铺数据。
- 在折叠区实测的标题为 Polaris Inter 回退链、13px/20px、600 字重、`rgb(48,48,48)`；一个档位标题输入内层为 13px、32px 高、水平 padding 12px。该输入的可见外边框由包装控件提供，不能据内层 `border:0` 判断整个控件无边框。

只读点击了设置、样式、Single、Duo 折叠标题，确认字段展开；未修改输入、开关或调用保存/发布。未检查颜色拾取器、日期弹层、删除确认、拖拽重排、错误/加载态的实际行为。

## 商品详情页组件

- 商品页是左图右文（窄桌面），Kaching 组件位于商品标题、价格之后；手机视口为单列，商品图和价格之后紧接组件。该参考商品未显示可供观察的多 Variant 选择器，不能从此页推断独立规格选择、缺货或混款逻辑。
- 组件标题为 `BUNDLE & SAVE`，左右各有细线；未选 Single 浅灰底，选中 Duo 白底且黑色约 2px 边框，卡片圆角 8px。选中圆点约 20 x 20px。Duo 右上有黑底白字推荐标记；折前总价划线。
- 常规视口实测 `.kaching-bundles` 宽 283px；Single 卡约 283 x 75px，底色 `rgb(237,237,237)`；Duo 卡约 283 x 92px，底色白色、内边距约 10px 20px。标题 14px/19.6px、700，档位名与主价格 20px/28px、700，副标题 14px/19.6px、400、`rgb(85,85,85)`；SAVE 标签约 12px，4px 8px padding、8px 圆角、`rgb(217,217,217)` 背景。组件字体回退为 Helvetica/Arial。
- 前台可访问性树中有 Single、Duo 两个按钮，以及主题提供的 Add to cart、Buy it now。价格示例为商品单价 $749.95；Duo 显示 `SAVE $224.98`、`You save 15%`、折后 $1,274.92 与划线 $1,499.90。后台预览选 Canada 时显示另一币值，故不能把这两套金额视为同一市场的像素快照。
- 390 x 844 视口截图显示标题、Single 和 Duo 卡在同一单列流中；截图底部有 Shopify 预览工具条，可能遮住组件下部，不据此推断组件裁切或移动端异常。

## 未验证边界

Hover、Focus、Disabled、Loading、弹窗/抽屉、加入购物车后的结果、售罄及库存不足、不同 SKU 价格、Variant 图片/色板/下拉框和后台手机响应式均未从本次参考页得到有效证据。后续若要高保真处理这些状态，需要用户提供可触发状态的参考商品/截图或允许进一步只读操作；不能凭参考首页的静态外观编造。参考产品的促销、A/B 测试、赠品、订阅和推荐应用超出 SHOPLINE 一期 Quantity Breaks 范围。
